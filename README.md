# VendorMind 🤖💼
> **Agentic Procurement & Vendor Negotiation System**

VendorMind is an autonomous AI Agent that automates the tedious procurement cycle for small businesses and IT teams by scouting vendors, conducting email outreach, comparing contract terms, and drafting counter-offer proposals.

## 🚀 Key Features

1. **Requirement Ingestion:** Accepts project specs, feature requirements, and budget constraints.
2. **Automated Vendor Scouting:** Scrapes public vendor pricing tiers and feature matrices.
3. **Outreach Execution:** Initiates automated email inquiries to vendors requesting custom enterprise quotes.
4. **Contract Parsing & Negotiation:** Extracts line items, evaluates SLAs against target budgets, and generates strategic counter-offer drafts.
